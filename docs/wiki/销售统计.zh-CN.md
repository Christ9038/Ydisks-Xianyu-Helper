# 销售统计

[English](Sales-Statistics) | 中文

**销售统计**（`/app/sales`）按时间范围汇总销售数据。统计范围是当前登录用户名下账号的订单（侧边栏对所有登录用户显示，不限管理员）。

## 时间范围

今天、昨天、三天内、7 天内、一个月内，或自定义日期范围（选择起止日期后点“应用”）。订单按**创建时间**、以浏览器本地时区的日期归属。“一个月内”为 30 天，默认选中“7天内”。

## 指标口径

三项指标并列展示，**互不抵扣**：

| 指标 | 口径 |
| --- | --- |
| 销售额 (CNY) | 状态为已发货 + 已完成的订单金额 |
| 已收货款 (CNY) | 状态为已完成的订单金额 |
| 退货货款 (CNY) | 状态为已取消的订单金额（确认取消即视为已退款） |

卡片下方是**按日趋势图**和**按日明细表**（订单数、销售额、已收货款、退货货款）。显示“暂无销售数据”表示该时间范围内没有已发货、已完成或已取消的订单。

## 金额如何计算

- 金额按整数**分**累加（不使用浮点累加），仅在展示时换算为元，因此合计与按日明细始终精确一致。平台如果返回了第三位小数，按四舍五入进位到分。
- 单笔订单金额必须在 0 到 **¥10,000,000** 之间。库中金额格式非法或超过该上限的订单（例如旧版本写入的异常值）会被**整单排除在所有指标之外**，也不计入订单数，一条脏数据不会再把“退货货款”等数字拉高。编辑订单、导入订单或同步订单时，超过上限的新金额会被直接拒绝。

要看收益、状态、商品分布，请使用[仪表盘](仪表盘.zh-CN)。
