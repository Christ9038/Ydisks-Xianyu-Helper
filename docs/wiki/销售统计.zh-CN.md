# 销售统计

[English](Sales-Statistics) | 中文

**销售统计**（`/app/sales`）按时间范围汇总销售数据。**仅管理员可打开**，统计范围为所有账号的订单。

## 时间范围

今天、昨天、三天内、7 天内、一个月内，或自定义日期范围（选择起止日期后点“应用”）。订单按**创建时间**、以你本地时区的日期归属。

## 指标口径

三项指标并列展示，**互不抵扣**：

| 指标 | 口径 |
| --- | --- |
| 销售额 (CNY) | 状态为已发货 + 已完成的订单金额 |
| 已收货款 (CNY) | 状态为已完成的订单金额 |
| 退货货款 (CNY) | 状态为已取消的订单金额（确认取消即视为已退款） |

卡片下方是**按日趋势图**和**按日明细表**（订单数、销售额、已收货款、退货货款）。显示“暂无销售数据”表示该时间范围内没有已发货、已完成或已取消的订单。

要看收益、状态、商品分布，请使用[仪表盘](仪表盘.zh-CN)。
