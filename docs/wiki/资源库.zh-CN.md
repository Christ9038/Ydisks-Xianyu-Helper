# 本地资源库

[English](Resource-Library) | 中文

**本地资源库**（`/app/library`，侧边栏在“在线聊天”下方）保存常用商品模板和图片，可一键把同款商品铺到多个账号。页面有两个页签：**商品模板**和**图片库**。

## 图片库

- 图片上传一次后可反复用作商品主图或规格图，单张不超过 **10 MB**，支持 PNG / JPG / GIF / WEBP，可多选，单次最多 20 张。相同内容的图片只保存一份，重复上传会提示“已存在”。
- 文件保存在上传根目录（`XIANYU_UPLOAD_DIR`）下的 `library` 子目录，无需修改 Compose。
- 支持按文件名搜索、大图预览、单张或批量删除。
- 图片卡片会显示“被 N 个模板引用”（按商品模板统计）。“发布商品”弹窗也可以直接从图片库选图。
- 勾选图片后可“删除所选”，也可“全选当前结果”或“清空选择”。

图片库支持按格式（JPG / PNG / WEBP / GIF）和引用（被模板引用 / 未被引用）筛选，排序有：最新上传、最早上传、文件名 A→Z / Z→A、文件大→小 / 小→大。有筛选条件时可点“重置筛选”恢复；仍被商品模板、关键词回复、账号默认回复、商品首次回复、图片卡密、快捷回复或发货模板引用的图片无法删除（HTTP 409），提示会列出引用位置，需先移除引用。图片选择器同样可按格式筛选和排序。

图片库图片可在这些位置直接选用：发布商品与商品模板、发货模板的图片消息、图片类型卡密、关键词/默认回复、商品首次回复，以及在线聊天发送图片和快捷回复图片。

## 商品模板

一个模板包含发布商品所需的全部内容：

- 模板名称、商品标题、描述、售价、库存、原价（可选）、邮费（包邮/按距离计费/一口价邮费/无需邮寄）；类目固定为电子资料，发货地使用各账号在平台上的默认值。
- **1–9 张主图**（来自图片库，第一张为封面，可用箭头调整顺序），以及每个规格值的可选规格图。
- 多规格配置（SKU 组合的价格与库存）。
- **发布后自动化**：付款后自动发货（卡密组或发货模板，按完整规格组合分别配置）、评价赠品，以及求评价设置（发货后小时数、最多发送次数、发送延迟秒数、消息内容）。多规格商品必须为每个规格组合配置。

商品模板列表可搜索模板名称、标题、描述或类目，可按规格（单规格/多规格）、付款发货（已启用/未启用）、邮费模式（包邮/按距离/固定邮费/无需邮寄）筛选，排序有：最近更新、最早更新、名称 A→Z、价格低→高 / 高→低、库存多→少。每张模板卡片提供“编辑”“复制”“删除”；可“全选当前结果”，或勾选后点击“发布所选”“删除所选”（已发布的商品不受影响）。

## 从 Excel 批量导入模板

商品较多时，可以用表格一次导入为模板，之后再按需选择账号发布：

1. 在“商品模板”页点击“从 Excel 导入”，可先点“下载导入模板”。表格列与[批量铺货](批量铺货.zh-CN)相同，但**没有“账号ID”**；首列“模板名称”可留空，留空时取标题前 100 个字。支持 `.xlsx`、`.csv`、`.tsv`，单次最多 300 行、表格最大 20 MiB。
2. “图片”列可填图片压缩包内的路径（需同时上传 zip，最大 200 MiB）或 `http/https` 网址。网址图片在导入时下载进图片库，之后发布不再依赖外链；内容相同的图片会自动去重。
3. 付款发货内容同样支持 `T模板ID` 与“变量.xxx”列，每行一个网盘链接时无需逐个建卡密或发货模板（写法见[批量铺货](批量铺货.zh-CN)）。邮费模式填 `none` 表示无需邮寄，`free` 表示包邮。
4. 点击“预检”：逐行显示能否导入及原因（例如价格非法、压缩包缺图、发货模板缺少变量），与已有模板或表格内其他行标题相同时给出提示但不阻止导入。预检不会写入模板，也不会下载图片。
5. 点击“导入 N 个模板”：只导入通过的行，进度分段推进，可随时“停止导入”（已导入的模板保留）。某行导入失败（如图片下载失败）不影响其他行，失败原因会列出。
6. 导入完成后，新模板会在列表中自动勾选，直接点击“发布所选”选择账号即可。

导入全程不访问闲鱼平台接口。未完成的导入任务在 24 小时后自动清理。

## 把模板发布到账号

1. 勾选一个或多个模板，点击“发布所选”。
2. 选择目标账号（仅列出可用账号）和发布间隔（秒，0–3600；0 表示使用默认的 5 秒）。
3. 系统生成“模板 × 账号”预检表，无效行会显示原因，可用“只看需修正”筛选。
4. 确认后沿用[批量铺货](批量铺货.zh-CN)的串行发布、强制间隔、进度展示和失败重试。单批行数（模板数 × 账号数）不设上限，全部排队逐个发布，弹窗会按发布间隔提示预计耗时；遇到平台风控、登录失效或 Token 刷新耗尽时，会立即停止本批剩余商品，不会继续请求。

模板里配置的自动化规则会按完整规格组合写到每个已发布的商品上。
