# 在线聊天与账号自动任务

## 在线聊天

进入“在线聊天”后，顶部按账号显示 Tab；每个账号拥有独立的会话列表和消息状态。下方是标准两栏布局：左侧为会话列表，右侧为当前会话消息窗口。

聊天功能包括：

- 会话联系人、头像、昵称、用户 ID、商品摘要和未读数；列表按闲鱼会话最后消息时间倒序。
- 进入会话后优先读取本地缓存，再从闲鱼历史消息接口补齐记录；底部可继续加载更早消息和更多历史联系人。
- 文本消息、闲鱼文字表情和图片发送。当前不支持从管理后台发送视频，因此界面不提供视频发送按钮。
- 发送方按“对方/我”区分，并显示对应头像；账号之间的会话和实时消息完全隔离。
- 应用使用后端 `/api/v1/chat/ws` 推送实时事件；刷新或重连后仍以历史接口和本地数据库为准，不只依赖 WebSocket 存续期间收到的消息。

### 官方消息识别

闲鱼的交易卡片和平台通知不能当作普通用户消息处理。当前按协议元数据识别：

- `contentType=14`：平台通知类消息；
- `contentType=26`：交易卡片；
- 发送方用户 ID `1400`：闲小蜜；
- “发来一条新消息”：官方通知占位内容。

识别出的消息不会进入关键词、默认回复或 AI 回复链，并在聊天窗口中以居中的系统消息卡片展示。联系人分页返回的空会话壳不会导入列表，避免出现只有“暂无消息”的伪联系人。

如果昵称或头像缺失，点击会话列表刷新按钮；系统联系人闲小蜜使用平台头像和固定名称，不应把订单卡片标题当成用户昵称。

## 账号自动评价

入口为“账号管理 → 自动评价与每日擦亮”。自动评价是账号级开关，不针对不同买家配置不同文案：

1. 开启“自动评价”；
2. 填写统一好评文案，最多 500 个字符；
3. 保存后，后台持续扫描该账号的待评价订单；
4. 每个待评价订单按交易订单 ID 幂等执行，已经处理过的订单不会重复评价。

它不是每日任务。可以点击“立即评价”执行一次扫描，也可以依赖后台持续扫描。账号停用或暂停时不会执行。

## 每日自动擦亮

每日擦亮同样是账号级开关，但与自动评价不同：

- 按北京时间判断执行时间；
- 每个账号每天最多执行一次；
- 默认执行时间为 `03:00`，可在 `HH:mm` 范围内调整；
- 后台调用商品列表接口并逐个执行擦亮；当前实现按每页 20 条、最多 20 页读取商品；
- 可以点击“立即擦亮”手动触发，但当天已成功执行时会被幂等保护跳过；
- 页面会显示最近完成时间、本次发现数量、成功数、失败数和跳过数。

如果执行中部分商品失败，任务会记录失败原因并进入可重试状态；不要仅根据按钮返回就判断所有商品都已成功，应该查看本次执行结果。

## 与交易自动化的边界

“账号自动评价/每日擦亮”处理账号级任务；“自动化规则”处理订单和聊天触发的业务规则：

- 付款后自动发货；
- 评价后发送赠品；
- 超时未评价求评价；
- 关键词回复、默认回复和 AI 回复。

闲鱼官方系统消息只用于平台事件识别，不应被配置为普通买家关键词触发自动回复。
