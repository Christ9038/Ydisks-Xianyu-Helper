# 常见问题

[English](FAQ) | 中文

账号被风控、扫码一直提示“要求安全验证”，请直接看[账号被风控了怎么办](风控处理.zh-CN)。下面是其他常被问到的问题。

## 安装和升级

**管理员账号是哪个？忘了密码怎么办？**
用户名固定是 `admin`，密码是你第一次打开管理页面时设置的。忘了的话用命令行重置：
`go run ./cmd/server -init-admin -db <数据库路径> -admin-password '新密码'`。Docker 用户改 `XIANYU_ADMIN_PASSWORD` 即可。

**Docker 怎么升级？数据会丢吗？**
不会丢。拉取最新镜像，删掉旧容器，再用原来的参数重新创建就行。用 Compose 的话执行 `docker compose pull && docker compose up -d`；用 Portainer 的话先拉镜像再点 Recreate。只要数据卷和 `XIANYU_DATA_KEY` 沿用原来的，账号和订单都在。注意只“重新部署”但没拉新镜像，还是会跑旧版本。

**部署在哪里比较好？**
最好放在自己家里，比如 NAS、软路由，用 Docker 跑。云服务器和机房的 IP 很容易被闲鱼风控盯上。

**能用 MySQL 吗？**
可以，除了 SQLite，也支持 MySQL 和 PostgreSQL，配置方法见[部署与数据库](部署与数据库.zh-CN)。交流群目前只有 Telegram 群，没有微信群。

**macOS 安装包装不上。**
安装包如果没有签名，会被系统拦截。到“系统设置 → 隐私与安全性”里，找到被拦截的提示点“仍要打开”，再装一遍。还不行的话，反馈时请带上 macOS 版本、芯片（Apple 芯片还是 Intel）、安装包文件名和完整报错。

**Windows 更新时提示“Windows 服务注册失败”。**
目前没有确认的原因。可以先试试以管理员身份运行安装包，并先把旧的 `YdisksXianyuHelper` 服务停掉；还不行请附上完整报错提交问题。

**通知测试提示“拒绝访问非公网地址”。**
程序为了安全，不允许通知地址解析到内网 IP。常见原因是你开了代理，而且代理用了 fake-ip 模式（比如 mihomo），把通知服务器的域名解析成了一个内网地址。把这个域名加进代理的 fake-ip 过滤列表就行。

**浏览器通知提示“权限已拒绝”，或者没有声音。**
去浏览器的站点设置里，允许这个网址发送通知（浏览器一般要求用 HTTPS 或 `localhost` 访问）。提示音的开关在“系统设置 → 基础设置”里。

**程序是怎么收发消息的？走官方 API 吗？**
是参照闲鱼网页版自己的协议（WebSocket 加 MTOP 接口）来收发的，不是用无头浏览器去刷页面。

## 商品、卡密和发货

**API 制卡的请求头保存后再打开，怎么看不到了？**
这是故意的。API 卡里可能有第三方的密钥，出于安全不会再显示到页面上，要改的话重新填写一遍。

**多规格商品总是命不中自动发货。**
规则要和订单的**完整规格组合**对上才会发货，不会按部分规格去猜。升级到较新的版本，并检查每个规格组合是否都配了规则。

**自动化规则里选不到账号。**
确认已经建好了卡密库存，并且账号处于启用状态。

**能对接卡商的 API 自动发货吗？**
可以，卡密库存里选 API 类型，填请求模板就行。

**二人小刀的订单一直不发货，需要免拼。**
免拼是账号管理里一个独立的开关。流程是这样的：收到“待刀成”时，如果开了免拼就执行一次免拼；等收到“我已成功小刀，待发货”之后才会发卡；发卡成功后，再按“自动确认发货”的开关去确认发货。没开免拼的账号，则直接等到“待发货”阶段再发卡。

**服务预约这类 ¥0 的订单为什么没发卡？**
这是有意设计的：付款后自动发货有成交金额检查，0 元订单不会发卡密，避免误发。

**发布商品报“系统无法定位您所在的行政区”。**
实物商品必须有位置，虚拟商品一般不需要。新版本发布时可以手动选择发货地区。

**订单管理里“导入订单”的表格模板在哪下载？**
没有，那是历史遗留功能。直接用“同步订单”就好。

**账号默认回复，我自己当买家时也会触发。**
默认回复是按账号生效的，目前不能区分身份。建议用关键词规则限定范围。

## 评价和 AI

**自动评价突然不工作了。**
先升级到最新版，以前有两个已修复的问题：确认收货的通知把订单号解析错了；评价候选列表只取前 200 条，被已评价的订单占满后，新订单就排不进来了。另外，超过 30 天的订单，闲鱼本身就不允许再评价。

**重新启用“求评价”规则后，一下子给一堆旧订单发了消息。**
这个已经改了：规则里有“仅处理最近 N 小时内发货的订单”，更早发货的订单不会再被打扰。详见[自动化规则](自动化发货与回复.zh-CN)。

**AI 回复没反应，但模型测试是成功的。**
先看三点：API 地址要是兼容 OpenAI 格式、一般以 `/v1` 结尾；先在 AI 设置里点“测试连接”；还有，AI 回复目前主要用来应对砍价，买家问别的问题时可能不会回复，需要在账号里把 AI 模式切成“全场景客服”。

**买家发“转人工”之类的词，能通知我吗？**
暂时不行。买家的普通消息提醒还是靠闲鱼 App 自己的推送，程序里没有关键词通知。
