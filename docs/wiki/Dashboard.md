# Dashboard Guide

[中文](仪表盘.zh-CN) | English

## Purpose

Dashboard shows the current operating overview. It does not modify orders, inventory, or products. Metrics are grouped by time range and are useful for daily checks and pre-campaign reviews.

## View operating data

1. Sign in and open Dashboard.
2. Select Today, Yesterday, Last 3 Days, Last 7 Days, or Last Month.
3. Select Custom to enter a start and end date, then click Apply.
4. Review cumulative revenue, active accounts/total accounts, order count, and remaining card inventory.
5. Continue with revenue trends, product sales ranking, order-source distribution, and the order details included in the statistics.

Included orders are pending shipment, shipped, and completed orders with valid amounts. Order details can be searched by order ID, product, or buyer.

The revenue trend uses an area chart when there are more than 2 data points and bars otherwise; "item order share" and "item amount (TOP5)" are shown too. Order-detail search only covers already loaded rows. A custom date range takes effect only after you click Apply; failed validation just shows a hint and keeps the current range.

## Daily checks

- If the number of active accounts drops, check login state and risk-control notices in Account Management.
- If inventory approaches its safety threshold, replenish Card Inventory before continuing promotion.
- If orders exist but revenue or details look wrong, refresh first, then compare with the original order in Orders.
- Dashboard reflects saved data. Refresh again later if a recent sync or delivery is not immediately visible.
