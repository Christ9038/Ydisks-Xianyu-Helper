# 运行日志

[English](Runtime-Logs) | 中文

**运行日志**（`/app/logs`）展示服务进程内存中保留的最近日志，无需登录服务器翻文件即可排查问题。**仅管理员可打开该页面。**

## 功能

- **过滤**：按最低等级（Debug 及以上 / Info 及以上 / Warn 及以上 / 仅 Error）、**来源**和关键字（接口名、路径、错误文本或属性值）。
- 来源包括：内部接口（`http`）、闲鱼接口（`mtop`）、自动化、消息引擎、WebSocket、凭证续期、通知投递、其他。
- **暂停/继续**自动轮询，**刷新**从头重新加载，**清屏**（仅清空显示），以及“自动滚动到最新”。
- 展开一行可查看请求 ID、接口名、失败分类、`ret` 摘要、账号 ID、商品 ID 等属性。属性值在离开服务端前已脱敏，不会出现 Cookie 或 Token。

## 注意事项

- 内存中只保留有限条数的最近记录（默认 2000 条），旧记录被挤出时页面会出现黄色提示。需要长期留存请查看日志文件（见[部署与数据库](部署与数据库.zh-CN)）。
- 默认 `info` 级别下，接口调用只记录失败与警告；需要每次调用的明细，请在“系统设置”把日志等级调为 `debug`。
- 该页面自身的轮询请求不会写入请求日志，不会自我刷屏。
- 典型用法：来源选 `mtop`、关键字填 `RGV587`，确认是否触发风控，参见[风控处理](风控处理.zh-CN)。
