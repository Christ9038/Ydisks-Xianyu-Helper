# 批量铺货（中文）

[English](Bulk-Listing) | 中文

批量铺货会先预检，再启动后台发布任务。它最多一次处理 50 行商品；建议先用 1 行测试资料包验证后再跑正式批次。

## 1. 准备资料包

必需文件为 CSV、XLSX 或 TSV 表格（XLSX 只能包含一个工作表，不支持旧版 `.xls`）；如引用本地图片，再提供 ZIP 图片包。在“商品管理 → 批量铺货”中点击“下载CSV模板”可避免表头错误；该模板不含最后一个可选列“求评价延迟秒”，需要时请在表头末尾手动添加。

推荐中文表头：

```text
账号ID,标题,描述,价格,原价,库存,邮费模式,邮费,图片,类目ID,类目名称,频道类目ID,淘宝类目ID,付款发货启用,付款发货内容,评价赠品启用,评价赠品内容,求评价启用,求评价等待小时,求评价文案,求评价最多次数,求评价延迟秒
```

也支持英文表头，建议不要与中文混用；表头不区分大小写，并忽略空格、下划线和连字符，另有若干别名，见 `docs/批量铺货使用文档.md` §2.1。每行一个商品；`账号ID` 可留空，留空时使用上传页选择的“默认发布账号”。

### 必填与格式

- 标题非空，价格大于 0（最多两位小数）；库存为正整数，留空默认 1。
- 邮费模式留空默认为包邮，可写 `free`/`包邮`/`free_shipping`、`fixed`/`固定邮费`/`一口价邮费`（请填写邮费，不能为负；预检只校验格式和不为负，留空会按 0 元提交）、`distance`/`按距离计费`/`distance_fee`、`none`/`无需邮寄`/`不需要邮寄`/`no_shipping`。
- 每件商品 1–9 张图片，多个用英文分号 `;` 分隔。可用公开可访问的 `http(s)://` URL（预检只检查开头，实际下载在发布该行时进行，失败的行会发布失败），或 ZIP 内相对路径（预检会检查文件是否存在）。
- 上传页的默认类目可以留空。需要指定时，先选择账号，再输入关键词，由闲鱼推荐接口返回完整类目信息。表格的“类目ID + 类目名称 + 频道类目ID”可覆盖当前行；三列必须同时填写。
- “淘宝类目ID”按闲鱼推荐响应填写；“电子资料”的值为空，应保持为空。
- “求评价延迟秒”可选，填写大于等于 0 的整数（预检不校验该列）；留空时默认立即发送提醒。
- 本地图片 ZIP 最大 200 MiB（最多 500 个文件、解压后总计最多 500 MiB），单图最大 10 MiB；表格最大 20 MiB。
- CSV 使用 UTF-8，建议带 BOM。

### 自动化列

“付款发货内容”和“评价赠品内容”格式相同：

```text
卡密组ID:每件份数:延迟秒;卡密组ID:每件份数:延迟秒
```

例如 `101:1;102:2:30`：先从组 101 发 1 份，再等待 30 秒从组 102 发 2 份。份数省略时为 1（须大于 0），延迟省略时为 0（须在 0–3600 秒之间）。卡密组 ID 从“卡密库存”复制。

每个商品要发不同内容（如网盘链接）时，可以引用一个共享的[发货模板](发货模板.zh-CN)：内容列写 `T模板ID`（可带延迟 `T12:30`，也可与卡密混写 `101:1;T12`），模板里的 `{{custom.link}}` 对应表头为 `变量.link` 的列，每行填本商品的链接；`{{cards.main}}` 对应表头为 `模板卡密.main` 的列，填 `卡密组ID:每件份数`。导入时不会新建卡密组或模板；模板停用、缺少变量或卡密绑定时，预检会直接指出该行缺哪一项。网盘等虚拟资源的邮费模式请填 `none`（无需邮寄），`free` 表示包邮。求评价还可单独设置“求评价延迟秒”，默认 0。启用值可写“是”、`true`、`1`、`on`（另接受 `yes`、`y`、`开启`、`启用`，不区分大小写）；不启用写“否”、`false`、`0` 或留空，其他内容也按不启用处理。启用后，发布成功的商品会创建对应的自动化规则（付款发货规则的发货动作之后会固定追加“确认发货”动作）。

完整字段规范和示例见仓库中的 `docs/批量铺货使用文档.md`。

## 2. 后台操作

1. 在“商品管理”点击“批量铺货”（打开时若存在进行中的任务，会直接恢复到该任务；关闭弹窗后该按钮会显示为“继续批量任务”）。
2. 选择“默认发布账号”（必选）；表格某行未填账号 ID 时会使用它，填写则仅覆盖当前行。
3. 默认类目可以留空；需要整批固定类目时，输入关键词并点击“获取类目”。
4. 选择表格；表格引用本地图片时同时选择 ZIP。可按需调整“商品发布强制间隔”（1–3600 秒，默认 5 秒）：图片会提前上传，只有最终发布请求之间才至少等待该时间。
5. 点击“开始预检”，确认每一行的类目策略正确，再处理账号不存在或不属于当前用户、卡密组不存在、图片路径不匹配、固定邮费格式错误或价格为 0 等错误。每行显示“可发布”或“需修正”，“问题”列给出具体原因。预检结果里的行号按非空数据行计数（表头为第 1 行），空行不占行号。
6. 点击“确认发布 N 个商品”启动任务；只要有“可发布”行即可启动，“需修正”行不会发布，也不会被“重试失败项”重试，需修改表格后重新预检（可点“返回修改”放弃本次预检）。任务在后台运行，关闭弹窗后再次点击“批量铺货”或“继续批量任务”即可恢复到进行中的任务，任务结束后也可点“最近批次结果”查看。
7. 在任务详情查看成功、失败、等待与进行中行。需要时点“取消任务”；正在提交的单件商品可能继续完成，此时按钮显示“正在保存远端结果并安全取消…”。
8. 对可重试失败项使用“重试失败项”（远端结果不确定的行会提示“禁止自动重试，请人工核对闲鱼商品列表”，不会被重试），并在任务结束后点“下载结果”获取结果 CSV 留档。

### 类目选择顺序

类目优先级为：表格当前行指定类目 > 上传页通过关键词获取的默认类目 > 闲鱼根据商品标题、描述和图片自动识别 > “电子资料”最终兜底。只要用户指定了类目，就不会再由自动识别结果覆盖。接口超时、鉴权失败、风控等错误不会被最终兜底掩盖。

批量铺货面向虚拟商品：“批次发货地（可选）”可以留空；填写后整个批次使用同一个发货地，并随任务保存用于恢复和重试。指定类目只解决商品类型识别，不会改变虚拟发货流程。

## 3. 常见问题

- **图片找不到**：ZIP 内路径必须与表格完全一致，使用 `/`，不能以 `/` 开头或包含 `..`。
- **未能自动识别类目**：系统会自动使用“电子资料”最终兜底；接口超时、鉴权或风控错误仍会正常提示。
- **类目 ID 从哪里取**：在上传页输入关键词获取，无需手工查找或填写底层 ID。
- **自动化不生效**：检查卡密组 ID、账号归属、启用列和库存；发布成功后仍应查看自动化规则是否已创建。
- **任务中断**：先重新点击“批量铺货”/“继续批量任务”或“最近批次结果”确认状态，避免重复新建整批任务；仅重试失败行。
