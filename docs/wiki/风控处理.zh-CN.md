# 账号被风控了怎么办

[English](Risk-Control-Troubleshooting) | 中文

账号卡片上出现“闲鱼要求安全验证，请重新扫码并完成验证”、“接口续期已更新登录凭证，正在重新连接”，或者同步订单时报 `PERMISSION_EXCEPTION::无权限访问`，基本都是同一件事：**闲鱼把这个账号的登录凭证（Cookie）标记成了“有风险”**。

这是平台的判断，不是程序坏了。程序没法替你过人脸、滑块这些验证，能做的是：你在浏览器里把验证过掉，再把“过了验证的 Cookie”交给程序。

## 先说结论：为什么重新扫码没用？

账号还处在风控状态时，每次扫码拿到的都是一个**同样带风险标记的新 Cookie**，扫多少次都一样。所以别再反复扫码了，按下面的步骤，用浏览器里过了验证的 Cookie 来恢复。

## 操作步骤（以 Chrome / Edge 为例）

**第一步：在电脑浏览器里登录闲鱼网页版，并通过验证**

1. 用电脑打开 [goofish.com](https://www.goofish.com)，登录被风控的那个账号。
2. 点进**消息**页面。如果弹出滑块、人脸或短信验证，按提示完成。
3. 尽量使用和程序**同一个网络**（同一个出口 IP）的电脑来操作。程序在家里的 NAS 上，你却用手机流量或者开着 VPN 去验证，换了 IP 之后很可能又被重新要求验证。

**第二步：打开开发者工具，找到那个 `token` 请求**

1. 在消息页面按 `F12`（Mac 是 `Option + Command + I`），切换到顶部的**网络**（Network）标签。
2. 建议勾选“停用缓存”。
3. 在筛选框里输入 `token`。
4. **按 `F5` 刷新页面**（面板是打开着的时候刷新，请求才会被记录下来）。
5. 列表里会出现几条记录。点名字像 `1.0/?jsv=2.7.2&appKe...` 的那一条；名字以 `auth?token=...` 开头的那条不是，别点它。

**第三步：复制请求头里的 Cookie**

1. 点开那条请求，在右侧选**标头**（Headers）。
2. 往下找到“**请求标头**”（Request Headers）这一栏，里面有一行 **Cookie**。
3. 把它**整行的值**复制出来。这是一长串用分号隔开的内容，类似 `xxx=...; xxx=...; ...`，通常包含 `unb=`、`_m_h5_tk=` 等字段。右键这一行选“复制值”，或者双击值后全选复制都可以。

> 注意：要复制的是**这个请求发出时带的 Cookie**（请求标头里的），不是“应用/存储”里看到的 Cookie，也不是“响应标头”里的 `set-cookie`。复制错了位置是最常见的失败原因。

**第四步：粘贴到系统里**

账号卡片上提示需要验证时，会出现一个“**粘贴无风控 Cookie**”按钮，点它就会打开编辑窗口。也可以直接进入“账号管理 → 编辑账号”，把 Cookie 粘贴到 Cookie 输入框里保存。

保存后等一会儿，账号状态变成在线就恢复了。

## 粘贴了还是不行？逐项检查

- **网页版真的过了验证吗？** 如果你登录网页版时根本没有弹出任何验证，那可能是 Cookie 复制得太早，风控还没被触发或还没处理。可以多刷新几次消息页，等它弹出验证、完成后，再复制一次。有人就是第一次复制失败，网页上出现滑块并通过后，第二次复制才成功的。
- **复制的位置对吗？** 必须是 `token` 请求的“请求标头 → Cookie”。
- **网络环境一致吗？** 开关 VPN、切换代理节点、换网络，都会换 IP，可能让刚过的验证又失效。有人切了 VPN 后几分钟 Cookie 又不行了。
- **提示“WS Token 即将到期，正在主动轮换”并且一直恢复不了**：说明用的不是刚刚验证后的新 Cookie，重新做一遍上面的步骤，并且在通过验证之后马上复制。
- **粘贴的 Cookie 保存后又消失了**：说明平台仍然拒绝它，系统自动丢弃了。同样是重新通过验证后再复制。
- **等几个小时再试。** 有账号没做任何处理，隔几个小时后自己恢复了；也有人反馈重启一下容器后恢复，不过这个不保证有效。

## 订单同步提示 PERMISSION_EXCEPTION

这说明这个 Cookie 的“订单详情”接口被风控了。到闲鱼网页版里进入“我的闲鱼”，随便点开一个商品或订单，如果弹出验证就过掉，然后按上面的步骤重新复制 Cookie 粘贴回账号，再同步订单。建议同时升级到较新的版本。

## 怎么尽量避免被风控

- **部署在自己家里**：NAS、软路由或者家里常开的电脑，用 Docker 跑。机房、云服务器（包括香港的）IP 特征很明显，更容易被盯上。
- **出口 IP 保持稳定**：别频繁切 VPN、换代理。
- **不要加 `-no-browser`**：验证和订单详情的兜底都要用到 Chromium，除非确实装不了 Chromium 才关。
- **一个账号只在一个地方运行**：别多台机器同时登录同一个账号。
- 程序本身对闲鱼接口做了限速（同一账号两次请求至少间隔 2 秒，后台批量任务至少 5 秒），一旦发现风控会立刻停止批量任务，不会越撞越多。

## 常见的误会

- “提示 API 失效了”：多半是你的网络问题。比如日志里出现 `wsarecv ... forcibly closed`、`server misbehaving`，是本机网络或 DNS 连不上闲鱼，换个网络环境、检查 DNS 就好，接口本身是正常的。
- 网络短暂断开后账号会不会一直离线：不会，新版本会按 5 秒、15 秒、30 秒、60 秒、之后每 2 分钟的间隔自动重连，只有闲鱼明确拒绝登录才会停下来。

另外请**不要**把 Cookie 发给别人、贴到群里或者提交到 Issue 里，它等同于账号的登录权限。
