# 新手入门（傻瓜式分步手册）

[English](Quick-Start-Guide) | 中文

本页带你在约 30 分钟内从“什么都没装”走到“第一单自动发货成功”。请按顺序操作，不要跳过第 8 步的测试。每一步末尾都附有完整手册链接，需要细节时再点进去看。

## 开始之前需要准备

- 一台可以长期开机的电脑或服务器（Windows、macOS、Linux 或任意支持 Docker 的主机）。
- 手机上的**闲鱼 App**，并已登录要自动化的卖家账号。
- 一件用于测试的商品（低价或虚拟商品），以及**另一个闲鱼账号**用来下测试单（不能购买自己的商品）。
- 想发给买家的内容，例如兑换码或网盘链接。

## 第 1 步：安装并启动

选择最适合你的方式：

| 方式 | 适合谁 | 怎么做 |
| --- | --- | --- |
| Windows / macOS 安装包 | 个人电脑 | 运行与系统、架构匹配的安装包，会自动安装后台服务、托盘/菜单栏图标和程序所需的浏览器。 |
| Linux 安装包 | Linux 服务器 | 解压后执行 `sudo ./install.sh`。 |
| Docker Compose | 服务器、正式环境 | 复制 `.env.example` 为 `.env` 并填好必填项，执行 `docker compose up -d`。 |

详细步骤、必填环境变量和数据库选择见[部署与数据库](部署与数据库.zh-CN)。桌面安装包只监听 `http://127.0.0.1:59188`（仅本机可访问）；Docker 和源码运行默认监听所有网卡，服务器在公网时请用防火墙限制该端口。

> **请立刻备份 `XIANYU_DATA_KEY`。** 它用于加密已保存的 Cookie、密码、AI 密钥和通知凭据；丢失或之后更换，会导致这些数据无法解密。

## 第 2 步：打开管理页面并创建管理员

1. 浏览器打开 `http://127.0.0.1:59188`（远程部署时换成服务器地址）。
2. 全新数据库会显示首次初始化页面：输入至少 8 位的密码并确认、提交。管理员用户名固定为 `admin`，提交后会自动登录。（Docker Compose 的密码来自 `XIANYU_ADMIN_PASSWORD`，直接登录即可。）
3. 请牢记这个密码，它保护着整个管理后台。

侧边栏列出所有页面。手机上底部导航栏是：仪表盘、聊天、账号、订单和**更多**（其余页面都在“更多”抽屉里）。

## 第 3 步：接入闲鱼账号

1. 打开“账号管理”，点击“扫码添加新账号”。
2. 用卖家账号的闲鱼 App 扫描二维码并在手机上确认。如果闲鱼要求人脸或安全验证，只在官方 App 内完成。
3. 等账号卡片出现，给它加一个**备注**（例如“主店”），方便区分多个账号。
4. 确认账号为**启用**状态并显示在线。

详见[账号管理](账号管理.zh-CN)。账号之后被风控时看[风控处理](风控处理.zh-CN)。

## 第 4 步：准备要发给买家的内容（卡密组）

1. 打开“卡密库存”，点击“添加新卡密”。
2. 输入名称，例如“测试卡密”。
3. 选择类型：
   - **文本**：每次发送相同的文字（第一次测试最合适，可放链接或使用说明）；
   - **批量库存**：每行一条，每个订单消耗一条（兑换码、账号等）。
4. 保存。新建的卡密组默认启用。

详见[卡密库存](卡密库存.zh-CN)。需要按固定顺序发送多条消息或图片时，之后再建[发货模板](发货模板.zh-CN)。

## 第 5 步：把商品同步进系统

1. 打开“商品列表”，在“同步商品账号”里选中你的账号，点击“同步商品”。
2. 确认测试商品的标题、价格和商品 ID 已出现。

商品还没上架到闲鱼时，可以在同一页面用“发布商品”，商品很多时用[批量铺货](批量铺货.zh-CN)。详见[商品管理](商品管理.zh-CN)。

## 第 6 步：打开自动发货并建立发货规则

1. 在“账号管理”点击该账号的“编辑”，打开“自动发货”，并决定是否开启“自动确认发货”：
   - 开启：发完卡密后程序会把闲鱼订单标记为已发货（适合即时发货的商品）；
   - 关闭：程序只发送内容，由你手动确认发货（适合需要较长时间交付的商品，更稳妥）。
   “自动免拼”只有在销售二人小刀商品时才需要开启，其他情况保持关闭，说明见[砍价订单与自动发货流程](砍价订单与自动发货流程.zh-CN)。
2. 打开“自动化规则”→“交易自动化”→“新建自动化”→“付款发货”。
3. 选择账号和测试商品，点击“添加发货内容”，选择“卡密库存”，选中第 4 步的卡密组，每件数量保持 1。
4. 勾选“启用规则”并保存。

详见[自动化发货与回复](自动化发货与回复.zh-CN)。

## 第 7 步：设置通知（推荐）

1. 打开“通知设置”，点击“新建渠道”（Bark、钉钉、飞书、企业微信、Telegram、邮件、Webhook 均可）。
2. 填写地址或令牌，勾选要使用该渠道的账号，保存。
3. 点击该渠道的“测试”。测试消息能收到，之后发货失败或需要人工处理时你也会第一时间收到通知。

详见[AI、通知与运维](AI、通知与运维.zh-CN)和[通知事件参考](通知事件参考.zh-CN)。

## 第 8 步：用一笔真实小额订单测试

1. 用另一个闲鱼账号购买你的测试商品（低价即可）。
2. 在“订单管理”观察：订单应当出现，并变为待发货/已发货。
3. 核对三件事：买家在聊天里收到了卡密文字；卡密库存发生了变化（批量库存时）；订单状态符合你的“自动确认发货”设置。
4. 到“在线聊天”查看会话，出现异常时（管理员）到“运行日志”排查。

测试通过后，才把同类规则关联到正式商品。卡密没有发出时，按[常见问题](常见问题.zh-CN)里的清单逐项检查。

## 第 9 步：按需逐步升级

## 日常使用清单

- 看一眼**仪表盘**和账号状态（在线、启用、没有风控提示）。
- 保证**卡密库存**充足；库存耗尽就无法发货，并会收到通知。
- 收到“需要人工处理”通知后，到“订单管理”处理，不要干等。
- 定期备份数据库和 `XIANYU_DATA_KEY`。
- 不要同时发起大量批量操作：程序会刻意拉开对闲鱼的请求间隔以避免风控（见[请求频率与风控设计](请求频率与风控设计.zh-CN)）。

## 在手机上使用

管理后台会适配小屏幕。底部导航栏提供仪表盘、聊天、账号、订单和“更多”；“更多”抽屉里有本地资源库、卡密库存、商品列表、销售统计、发货模板、自动化规则、通知设置和 API 管理，管理员还能看到系统与AI、运行日志，此外还有主题按钮（跟随系统/浅色/深色）和版本号。在线聊天一次只显示一个面板：先是会话列表，点开会话后显示消息（返回即回到列表）。订单页每单显示为一张卡片。服务器不在局域网内时，建议先配置 HTTPS 再用手机访问。

## 第一天常见问题

| 现象 | 检查什么 |
| --- | --- |
| 管理页面打不开 | 服务是否在运行？地址和端口 59188 是否正确？防火墙？见[部署与数据库](部署与数据库.zh-CN)。 |
| 扫码失败或账号掉线 | 在账号管理里重新扫码授权；遇到安全验证只在官方闲鱼 App 内完成。 |
| 付款后没有发卡 | 账号在线且启用？自动发货已开？规则已启用并关联了正确的商品/规格？卡密组已启用且有库存？见[常见问题](常见问题.zh-CN)。 |
| 订单一直停在“待发货” | 自动确认发货未开启或被平台拒绝，可在订单页点“立即发货”处理。 |
| 日志出现“风控”或 `RGV587` | 停止批量操作，按[风控处理](风控处理.zh-CN)操作。 |

## 名词速查

- **卡密组**：要发给买家的内容，可以是文本、一批兑换码、图片或接口取码。
- **发货模板**：按顺序发送的多条消息和图片，作为一次发货。
- **交易自动化**：未付款改价、付款发货、评价赠品、求评价四类规则。
- **小刀**：二人小刀订单，步骤顺序固定。
- **免拼**：请求闲鱼在不等待更多买家的情况下完成拼团订单。
- **人工接管**：你亲自回复买家后，自动回复会暂停一段时间。
