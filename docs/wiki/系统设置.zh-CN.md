# 系统与AI 使用手册（中文）

[English](System-and-AI) | 中文

“系统与AI”仅管理员可见，用于配置全局服务、AI、远程过验证和登录凭据。通知渠道和 SMTP 已移到[通知设置](AI、通知与运维.zh-CN)页面。

## 基础设置

1. 进入“系统与AI”。
2. 根据实际部署需要配置日志级别和日志格式。
3. 如需限制用户配置的 HTTP 请求只能访问公网，开启对应开关后保存。该设置会同时影响 API 发货、AI、HTTP 通知、远程图片和远程过验证服务，可能使内网地址无法访问。
4. 点击“保存所有配置”。基础设置保存后按页面提示重新启动服务的项目，要重启后才完全生效。

不要在这里粘贴 Cookie、通知令牌或数据库密码。系统配置的敏感值应使用环境变量或页面提供的加密保存方式，并备份 `XIANYU_DATA_KEY`。

## 配置 AI

1. 填写 OpenAI 兼容 API 地址，例如 `https://api.openai.com/v1`；不要填完整的 `/chat/completions` 路径。
2. 填写 API Key，点击“读取模型”。读取不到模型列表时可以手动输入模型名。
3. 保存系统设置。
4. 到“账号管理”打开目标账号的“AI 设置”，启用 AI 自动回复并设置砍价边界。

AI 默认只处理砍价；账号可切换为“全场景客服”模式以回复商品咨询、发货和售后消息，商品也可单独覆盖账号设置。AI 不处理的消息仍按关键词、AI 和默认回复链路处理。启用前请用低风险账号确认降价金额、折扣和最大轮次。

## 远程过验证

只有在已有可信远程服务时才填写“服务地址”和“服务秘钥”。配置后系统优先调用远程服务，网络不可用或超时才回退本机引擎；远程明确返回失败时不会重复触发本机验证。

“允许向远程服务传递账号 Cookie”默认关闭。只有确认远程服务可信且确实需要自动刷新验证链接时才开启。

## 修改登录凭据

填写当前密码后可以修改后台登录用户名和密码；新密码与确认密码必须一致。只想修改用户名时留空新密码即可。修改后使用新凭据重新登录，并妥善保存，不要与闲鱼账号密码混用。

## AI 连接测试

在 AI 模型设置中点击**测试连接**，会用已填写的 API 地址、Key 和模型发送一次真实的最小对话请求，在为账号启用 AI 之前验证完整链路。兼容 OpenAI 的服务，API 地址通常需要以 `/v1` 结尾。

## 敏感设置访问审计

读取或修改敏感设置（API Key、SMTP、通知凭据）时，会写入一条审计记录，包含操作用户、动作、资源和键名、结果与时间；密钥值本身不会被记录。
