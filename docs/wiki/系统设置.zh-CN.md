# 系统与AI 使用手册（中文）

[English](System-and-AI) | 中文

“系统与AI”仅管理员可见（页面标题为“系统设置”），用于配置全局服务、AI、远程过滑块和登录凭据。通知渠道和 SMTP 已移到[通知设置](AI、通知与运维.zh-CN)页面。

## 基础设置

1. 进入“系统与AI”。
2. 根据实际部署需要配置“日志输出等级”（Debug / Info / Warn / Error）和“日志输出格式”（Text / JSON）。选择 JSON 格式保存后需重启服务生效。
3. “续期日志保留天数”见下文；“新消息浏览器通知提示音”只保存在当前浏览器，收到买家新消息并弹出浏览器通知时播放提示音，需要先在在线聊天页开启浏览器提醒。
4. 如需限制用户配置的 HTTP 请求只能访问公网，开启“限制用户配置的 HTTP 出站请求只能访问公网”后保存。该设置会同时约束 API 发货、AI、HTTP 通知、远程图片和远程滑块服务，保存后立即生效，可能使内网服务无法访问。
5. 点击页面右下角的“保存所有配置”。需要重启才能生效的项目按页面提示处理。

不要在这里粘贴 Cookie、通知令牌或数据库密码。系统配置里的敏感值（AI API Key、SMTP 密码、远程过滑块秘钥等）使用 `XIANYU_DATA_KEY` 加密保存，请备份该密钥；保存后页面不会回显这些值，只提示“已配置”。

## 配置 AI

1. 填写 OpenAI 兼容 API 地址，例如 `https://api.openai.com/v1`；不要填完整的 `/chat/completions` 路径。留空时默认使用通义兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
2. 填写 API Key，点击“读取模型”。读取不到模型列表时可以手动输入模型名。
3. 点击“保存所有配置”。
4. 到“账号管理”打开目标账号的“AI 设置”，启用 AI 自动回复并设置砍价边界。

AI 默认只处理砍价；账号可切换为“全场景客服”模式以回复商品咨询、发货和售后消息，商品也可单独覆盖账号设置。回复优先级为：外部 API 回复、关键词回复、AI、默认回复，因此关键词始终优先于 AI，AI 没有处理的消息继续走默认回复。启用前请用低风险账号确认降价金额、折扣和最大轮次。账号侧各项设置的含义见[AI、通知与运维](AI、通知与运维.zh-CN)。

“读取模型”使用页面上当前填写的地址和 Key（未保存也可以），向 `<API 地址>/models` 发起请求；Key 留空时使用已保存的 Key，服务返回空列表或出错时页面显示错误信息。进入页面时会自动读取一次；若模型栏为空，会自动填入读取到的第一个模型。保存配置后模型列表会清空，需要时重新点击“读取模型”。

## AI 连接测试

点击**测试连接**，会用页面上当前填写的 API 地址、Key 和模型向 `<API 地址>/chat/completions` 发送一次真实的最小对话请求（内容“你好”，最多返回 64 个 token），在为账号启用 AI 之前验证完整链路。成功时显示模型名、耗时和 AI 的回复；失败时显示上游返回的错误。地址、Key 或模型留空时回退使用已保存的值，仍没有模型则提示先填写模型名称或点击“读取模型”。兼容 OpenAI 的服务，API 地址通常需要以 `/v1` 结尾。

## 远程过滑块

只有在已有可信远程服务时才填写“服务地址”和“服务秘钥”，两者都填写后才会启用。配置后系统优先调用远程服务，网络不可用或超时才回退本机引擎；远程明确返回失败时不会重复触发本机验证。

“允许向远程服务传递账号 Cookie”默认关闭，开启后请求中会附带账号 Cookie 和设备 ID。只有确认远程服务可信且需要由其自动重取过期验证链接时才开启。

## 修改登录凭据

“登录凭据”区域显示当前登录用户名。填写当前密码后可以修改后台登录用户名和密码：用户名 3–64 个字符，新密码至少 8 个字符，新密码与确认密码必须一致；用户名已被占用会提示冲突。只想修改用户名时留空新密码即可；用户名和密码都没有变化时服务端会拒绝（HTTP 400）。成功后当前登录会失效，页面稍后自动刷新，请用新凭据重新登录，并妥善保存，不要与闲鱼账号密码混用。

## 续期日志保留天数

“基础设置”中的“续期日志保留天数”控制凭证续期日志的自动清理，输入框范围 0–365，默认 10 天；填 0 表示不自动清理。（范围由输入框限制，服务端不另行校验。）

## 登录保护

后台登录只统计**失败**次数：同一 IP 5 分钟内失败 30 次，或同一用户名/邮箱失败 10 次，会暂时拒绝登录并返回“登录尝试过于频繁”（HTTP 429，带 `Retry-After`）；登录成功后清零该 IP 和该用户名/邮箱的计数。IP 取自 TCP 连接的远端地址，不读取 `X-Forwarded-For`，因此部署在反向代理后时，所有访客会共用代理的地址，30 次的 IP 上限由所有人共享。

## 敏感设置访问审计

访问以下敏感系统设置时会写入一条审计记录：`ai_api_key`、`smtp_password`、`qq_reply_secret_key`、`captcha.remote_secret_key`。触发场景包括读取系统设置（页面加载）、修改这些设置，以及系统实际使用它们时（读取模型或测试连接使用临时填写的 Key、通知发送读取 SMTP 密码、远程过滑块读取秘钥）。记录包含操作用户、动作（`settings.read` / `settings.write` / `settings.use`）、资源和键名、结果与时间；密钥值本身不会被记录。审计无法写入时，相关读取会被拒绝。
