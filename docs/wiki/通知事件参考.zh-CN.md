

## 渠道类型与填写项

| 渠道 | 必填 | 可选 |
| --- | --- | --- |
| Bark | Bark 服务器（如 `https://api.day.app`）、Device Key | 标题、铃声、分组 |
| 钉钉机器人 | Webhook URL | 加签密钥（安全设置勾选“加签”后生成，`SEC` 开头） |
| 飞书机器人 | Webhook URL | 签名校验密钥（安全设置选“签名校验”后生成） |
| 企业微信机器人 | Webhook URL | — |
| Telegram | Bot Token、Chat ID（群为 `-100…`，私聊为你的用户 ID） | — |
| 邮件 | 收件邮箱（发件走系统 SMTP，或开启“使用独立 SMTP”） | 独立 SMTP 的服务器、登录邮箱、密码/授权码、发件人显示名、SSL/STARTTLS |
| 自定义 Webhook | Webhook URL | 请求方法（默认 POST）、请求头（JSON） |

自定义 Webhook 收到的请求体为 JSON：`{"message": "通知正文", "timestamp": "2026-01-02 15:04:05", "source": "xianyu-auto-reply"}`，状态码低于 300 视为成功，300 及以上视为失败。QQ 邮箱需使用授权码而不是登录密码。

保存渠道后用“测试通知”验证。事件筛选里旧版的统一“交易”订阅，会在编辑时自动展开为四类自动化事件加“手动发货结果”和“需要人工处理”。
