# 发货模板使用手册（中文）

[English](Delivery-Templates) | 中文

## 创建模板

1. 进入“发货模板”，点击“新建模板”。
2. 填写模板名称，确认是否“启用模板”。
3. 输入一条或多条消息；消息会按页面顺序分别发送，消息不能为空。
4. 需要多条消息时点击“添加消息”，不需要的消息可以删除，但模板至少保留一条。
5. 点击“保存模板”。模板列表会显示消息数量和“已启用/已停用”，并提供“编辑”“删除”按钮。

每条消息要么是文本，要么是图片：在文本框下方选择“图片库”里的图片后，整条消息变为图片消息（内部令牌为 `{{library_image:图片ID}}`），不能与文字混写；清除图片后可重新输入文字。图片库见[本地资源库](资源库.zh-CN)。

## 可用变量

模板消息中可以直接使用以下变量：

- `{{order_id}}`：订单号
- `{{buyer_id}}`：买家 ID
- `{{buyer_nickname}}`：买家昵称，缺失时替换为空字符串
- `{{card_name}}`：规则绑定的卡密库存名称
- `{{cards.<变量名>}}`：规则绑定的卡密内容，例如 `{{cards.main}}`
- `{{custom.<变量名>}}`：自动化规则中填写的自定义文字

`cards.`、`custom.` 后的变量名只能使用英文字母、数字、下划线或短横线；不要包含空格或中文，也不要遗漏大括号。可以省略或写上 `delivery.` 前缀（如 `{{delivery.order_id}}`），两种写法等价。不支持商品 ID、商品标题等其他变量；保存时系统会校验变量拼写。模板变量仅用于发货模板。

## 在自动化规则中使用

1. 保存模板后进入“自动化规则”。
2. 在“付款后自动发货”或“评价后发送赠品”规则的发货方式中选择“发货模板”（另一选项为“卡密库存”）。
3. 为模板中使用的每个 `cards` 变量绑定卡密库存。
4. 为模板中使用的每个 `custom` 变量填写对应文字。
5. 保存并启用规则，用测试订单确认消息顺序和变量替换结果。

发货模板只用于付款后自动发货和评价后发送赠品，不用于拍下改价或求评价。仍被规则引用的模板不能删除；需要删除时先在相关规则中换成其他发货方式或模板。被规则引用的模板还不能增删或改名 `cards.`/`custom.` 变量（变量集合必须保持不变），否则保存会被拒绝。
