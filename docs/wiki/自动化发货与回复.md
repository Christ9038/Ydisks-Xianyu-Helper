# 自动化发货与回复

## 自动化的三种触发器

| 触发器 | 触发时机 | 标准流程 |
| --- | --- | --- |
| 付款后自动发货 | 收到付款系统卡片 | 匹配商品/规格 → 发送卡密 → 成功后确认发货。 |
| 评价后发送赠品 | 收到评价系统卡片 | 匹配商品/规格 → 发送赠品卡密。 |
| 超时未评价求评价 | 定时扫描已发货未评价订单 | 到达等待时间 → 发送提醒文案。 |

系统通知卡片只进入自动化判断；买家普通消息走关键词、默认回复和 AI 规则。

## 配置付款自动发货

前提：账号在线、商品已同步、卡密组已建立且有库存。

1. 进入“自动化规则”，选择“付款后自动发货”，点击新增。
2. 设置规则名称，选择目标账号和商品；商品有规格时为每个需要交付的规格建立对应配置。
3. 添加“发送卡密”动作，选择卡密库存、每件发送数量与是否启用。
4. 如需覆盖卡密组默认延迟，打开延迟覆盖并填写秒数；否则使用卡密组的默认延时。
5. 保存并确认规则处于启用状态。
6. 用测试订单确认：卡密内容已发送、卡密库存扣减正确、随后才确认发货。

按购买数量发货：动作中的“每件发送数量”会乘以订单购买数量。不要把每单总量误填为每件数量。

## 配置评价赠品与求评价

评价赠品的配置与付款发货相同，但触发器选择“评价后发送赠品”。赠品应使用独立卡密组，便于核对和补货。

配置求评价：

1. 新建“超时未评价求评价”规则，选择账号和商品。
2. 填写等待时间（发货后多少小时开始检查）、重复间隔及最多提醒次数。
3. 填写发送给买家的求评价文案，保存并启用。
4. 在测试订单上确认不会提前发送；达到最大次数后不再重复提醒。

## 异常处理与补发

“自动化规则”页面的异常区会列出可处理的自动化运行和延迟任务。先查看订单、库存、聊天记录和失败原因，再使用页面的“处理/解决”操作。不要在不确定已发货状态时直接重试，以免重复发卡。

需要人工补发时，在订单管理中定位订单，确认买家、商品和历史交付记录，再使用手动发货/补发能力。处理后记录原因并检查库存。

## 关键词与默认回复

在“自动化规则”的“关键词回复”页：选择账号 → 新增规则 → 填写关键词与文本或图片 URL → 保存。关键词规则用于买家普通消息。

“账号默认回复”只在关键词和 AI 都未处理该消息时使用。可设置文本、图片 URL 和“同一会话只回复一次”。上线前避免关键词、默认回复和 AI 提示词对同类问题给出互相矛盾的答案。
