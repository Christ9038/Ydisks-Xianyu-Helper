# 批量铺货资料包准备规格（AI Agent 指南）

> 本文档面向负责**准备资料**的 AI agent。你的任务是产出一份符合规格的商品表格（和可选的图片压缩包），交给运营人员通过后台"批量铺货"功能上传上架。
>
> **你不负责提交上传、不负责调用接口、不负责跑发布流程。** 你只产出文件。下面是文件必须满足的规格。

---

## 1. 你的交付物

| 交付物 | 必填 | 格式 | 说明 |
|---|---|---|---|
| 商品表格 | 是 | `.csv` / `.xlsx` / `.tsv` | 每行一个商品，第一行表头 |
| 图片压缩包 | 条件必填 | `.zip` | 仅当表格里有图片用本地路径引用时才需要；全用公网 URL 则不需要 |

**命名建议：**
- 表格：`商品清单_YYYYMMDD.csv`（或 `.xlsx`）
- 图片包：`images.zip`（或 `图片包_YYYYMMDD.zip`）

把两个文件放在同一目录交付即可。

---

## 2. 表格规格

### 2.1 表头（第一行）

表头必须完全一致（大小写敏感、无空格）。**推荐用中文表头**，复制下面这一行：

```
账号ID,标题,描述,价格,原价,库存,邮费模式,邮费,图片,类目ID,类目名称,频道类目ID,淘宝类目ID,付款发货启用,付款发货内容,评价赠品启用,评价赠品内容,求评价启用,求评价等待小时,求评价文案,求评价最多次数
```

如果用英文表头，对应是：

```
cookie_id,title,description,price,original_price,quantity,postage_mode,postage,images,category_id,category_name,channel_category_id,tb_category_id,paid_delivery_enabled,paid_delivery_contents,review_gift_enabled,review_gift_contents,review_request_enabled,review_request_after_hours,review_request_message,review_request_max_attempts
```

> 中英文表头二选一，**不要混用**。每个表头单元格的匹配是精确匹配，多空格、全角半角差异都会导致该列识别失败。

### 2.2 字段填写规则

#### 基础字段

| 列 | 必填 | 格式 / 取值 | 示例 |
|---|---|---|---|
| 账号ID | 是* | 闲鱼账号 ID（数字字符串）。*可留空，留空时由上传者在页面上指定默认账号 | `2222660684687` |
| 标题 | 是 | 文本，非空 | `会员组合包自动发货` |
| 描述 | 否 | 文本。留空时默认等于标题 | `下单后发送主卡和附赠卡。` |
| 价格 | 是 | 数字，单位元，必须 > 0 | `19.90` |
| 原价 | 否 | 数字，单位元。划线价 | `29.90` |
| 库存 | 否 | 整数，> 0，默认 1 | `10` |
| 邮费模式 | 否 | `free`（包邮，默认）或 `fixed`（固定邮费）。也接受 `包邮` / `固定邮费` | `free` |
| 邮费 | 条件必填 | 数字。邮费模式为 `fixed` 时必填；`free` 时留空 | `8.00` |
| 图片 | 是 | 1–9 张，多个用 `;` 分隔。每项是公网 URL 或图片包内相对路径 | `images/bundle-1.jpg;images/bundle-2.jpg` |

#### 指定类目字段（可选的逐行默认类目）

| 列 | 何时填写 | 格式 / 取值 |
|---|---|---|
| 类目ID | 当前行需要指定默认类目时 | 闲鱼商品类目 ID；必须和“类目名称、频道类目ID”同时填写 |
| 类目名称 | 填写了“类目ID”时 | 与类目 ID 对应的准确名称 |
| 频道类目ID | 填写了“类目ID”时 | 必须填写闲鱼推荐响应中的准确频道类目 ID |
| 淘宝类目ID | 闲鱼响应有值时 | 按原样填写；“电子资料”没有该值，保持为空 |

上传页面的默认类目可以留空。需要整批固定类目时，选择发布账号后输入关键词，由闲鱼推荐接口返回并保存完整类目信息。系统对每行按以下顺序处理：

1. 当前行填写了完整类目字段时，优先使用当前行类目。
2. 否则，上传页已通过关键词选择默认类目时，使用页面默认类目。
3. 前两项均为空时，调用闲鱼接口，根据标题、描述和图片自动识别。
4. 闲鱼明确没有识别结果时，最终使用“电子资料”（类目 ID `50023914`、频道类目 ID `202036301`）。

因此，表格和上传页都不指定类目时，系统会先自动识别，并只在没有匹配结果时使用“电子资料”。接口超时、鉴权失败和风控错误不会被最终兜底掩盖。

#### 自动化字段（可选，不填或填"否"表示不启用）

启用值接受：`1` / `true` / `yes` / `y` / `on` / `是` / `开启` / `启用`（不区分大小写）。
不启用填：`0` / `false` / `no` / `否` / 留空。

| 列 | 何时必填 | 格式 |
|---|---|---|
| 付款发货启用 | 否 | 启用值 |
| 付款发货内容 | 启用时必填 | 卡密组配置，见 §3 |
| 评价赠品启用 | 否 | 启用值 |
| 评价赠品内容 | 启用时必填 | 卡密组配置，见 §3 |
| 求评价启用 | 否 | 启用值 |
| 求评价等待小时 | 否 | 整数，> 0，默认 72。发货后多少小时未评价才提醒 |
| 求评价文案 | 启用时必填 | 文本，提醒消息内容 |
| 求评价最多次数 | 否 | 整数，> 0，默认 1 |

## 3. 卡密组配置格式

"付款发货内容"和"评价赠品内容"两列使用统一格式：

```
卡密组ID:每件份数:延迟秒;卡密组ID:每件份数:延迟秒
```

**规则：**
- 多条之间用 `;`（分号）分隔。
- `每件份数` 可省略，默认 `1`。
- `延迟秒` 可省略，默认 `0`。
- 卡密组 ID 必须是上传者已在"卡密库存"中创建好的组 ID（你准备资料时如果不知道 ID，留空并在交付说明里标注"需运营填卡密组 ID"）。

**示例：**

| 内容列填法 | 含义 |
|---|---|
| `101:1` | 从卡密组 101 发 1 份 |
| `101:1;102:2` | 卡密组 101 发 1 份 + 卡密组 102 发 2 份 |
| `101:1:0;102:2:30` | 卡密组 101 立即发 1 份；卡密组 102 延迟 30 秒后发 2 份 |

## 4. 图片规格

每个商品必须 1–9 张图片。两种方式二选一（可混用）：

### 4.1 用公网 URL（推荐，无需图片包）

直接在"图片"列填图片直链，多个用 `;` 分隔：

```
https://cdn.example.com/bundle-1.jpg;https://cdn.example.com/bundle-2.jpg
```

要求：`http(s)://` 开头，可公开访问，图片格式。

### 4.2 用本地图片（需交付图片包 ZIP）

把所有图片打成一个 `.zip`，表格"图片"列填**相对 ZIP 根的路径**。

**ZIP 结构示例：**
```
images.zip
├── bundle-1.jpg
├── bundle-2.jpg
└── sub/
    └── product.jpg
```

**表格"图片"列对应填法：**
```
bundle-1.jpg;bundle-2.jpg
sub/product.jpg
```

**图片限制：**
- 单张图片最大 10 MiB。
- 仅保留 `image/*` 类型（jpg / png / webp 等），其他文件自动忽略。
- 整个 ZIP 最大 200 MiB。
- 路径分隔符用正斜杠 `/`，不要用反斜杠。
- 路径不要以 `/` 开头，不要包含 `..`。

## 5. 资料包必须通过的校验

资料包上传后系统会逐行预检。**你交付前请按下表自检每一行**，任一项不通过该行会被标记无效（不会上架）：

| 检查项 | 规则 |
|---|---|
| 账号ID | 非空（或上传者用默认账号），且必须是上传者已授权的账号 |
| 标题 | 非空 |
| 价格 | > 0 |
| 库存 | > 0（默认 1） |
| 邮费模式 | `free` 或 `fixed`（或 `包邮` / `固定邮费`） |
| 邮费 | 邮费模式为 `fixed` 时必填且 ≥ 0 |
| 图片 | 1–9 张；本地路径必须在 ZIP 内存在；URL 必须是合法 `http(s)://` |
| 指定类目 | 当前行填写了任一类目字段时，“类目ID、类目名称、频道类目ID”必须同时存在；页面默认类目可为空 |
| 付款发货 | 启用时：内容列必填至少一条卡密组；卡密组 ID 必须属于上传者；每件份数 > 0；延迟秒 ≥ 0 |
| 评价赠品 | 同上 |
| 求评价 | 启用时：等待小时 > 0、文案非空、最多次数 > 0 |

---

## 6. 硬性限制

| 限制项 | 上限 |
|---|---|
| 单个资料包商品行数 | 50 条 |
| 表格文件大小 | 20 MiB |
| 图片 ZIP 大小 | 200 MiB |
| 单张图片大小 | 10 MiB |
| 单个商品图片数 | 9 张 |

> 超过 50 条请拆成多个资料包分别交付。

## 8. 交付前自检清单

逐项确认后再交付：

- [ ] 表格第一行是表头，且和 §2.1 完全一致（中或英，不混用）
- [ ] 每行都有账号ID（或确认上传者会用默认账号）
- [ ] 每行标题非空、价格 > 0、库存 > 0
- [ ] 邮费模式只填 `free` / `fixed`（或 `包邮` / `固定邮费`）；`fixed` 时邮费已填
- [ ] 每行图片 1–9 张，多个用 `;` 分隔
- [ ] 需要整批固定类目时，已在上传页通过关键词获取默认类目；否则保持为空
- [ ] 需要逐行指定类目时，“类目ID、类目名称、频道类目ID”同时填写；淘宝类目 ID 按接口响应填写
- [ ] 用本地路径的图片，在 ZIP 内对应路径都能找到
- [ ] 用 URL 的图片，链接是 `http(s)://` 且可公开访问
- [ ] 启用了付款发货/评价赠品的行，内容列按 §3 格式填写，卡密组 ID 已知（或已标注需运营补填）
- [ ] 启用了求评价的行，等待小时 > 0、文案非空、最多次数 > 0
- [ ] 总行数 ≤ 50；超过请拆包
- [ ] 表格文件 ≤ 20 MiB；图片 ZIP ≤ 200 MiB；单图 ≤ 10 MiB
- [ ] CSV 用 UTF-8 编码（建议带 BOM，Excel 打开不乱码）

满足以上，资料包即可直接上传，预检会全部通过。
