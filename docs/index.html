Core Capabilities

🔐

多账号启停与凭证续期

支持闲鱼 App 二维码扫码登录与密码登录，自动识别 Cookie/Token 时效，后台定时平滑续期与失效停用保护。

WebSocket 即时消息处理

按账号隔离在线聊天、历史消息和实时同步，支持闲鱼表情、文本/图片收发，并识别交易卡片与闲小蜜系统消息；普通消息继续支持关键词、默认回复及单次回复控制。

支持固定文本、批量导入卡密库与图片交付三种类型。灵活配置规格、延迟发送、库存追加与预警提醒。

无缝对接 OpenAI、通义千问、Ollama 等兼容接口。支持自定义提示词、控制议价轮次、折扣上限与自动拟人化沟通。

📊

批量铺货与商品管理

轻松同步闲鱼在售商品，支持 CSV + ZIP 素材包批量发布、关键词获取默认类目、逐行类目优先、自动识别与电子资料最终兜底、单商品手动挂载及自动化发货规则。

🔔

多渠道实时告警通知

集成 Bark、钉钉机器人、飞书、企业微信、Telegram、SMTP 邮件及 Webhook，账号掉线或异常发货秒级推送。

🛡️

Chromium 滑块与风控引擎

整合 Playwright-Go / Chromium 智能解决闲鱼滑块 CAPTCHA 与指纹校验，保障长时间稳定在线运行。

🗄️

多数据库与 AES-256 加密

原生支持 SQLite、MySQL 与 PostgreSQL，嵌入 Goose 自动迁移机制。敏感 Cookie 与 Token 采用 AES-256-GCM 高强度加密。

System Architecture

模块解耦，高并发 Go 运行时

Ydisks闲鱼助手使用 Go 语言实现核心通讯协议与账号状态机，绝大部分业务逻辑均在轻量级 Go 协程中执行；仅在涉及指纹与滑块风控时调度 Chromium。

  • internal/xianyu: 底层扫码/密码登录、MTOP 签名请求与 WebSocket 长连接
  • internal/engine: 单账号生命周期隔离、消息流水线与自动回复引擎
  • internal/automation: 发货、评价礼包、求评价调度与恢复机制
  • internal/browser: Playwright 浏览器自动化与冻结级滑块处理引擎

Deployment

几分钟内开箱即用

Terminal / Bash (Docker Compose One-Liner) 
# 1. 克隆仓库并复制环境变量模版
git clone https://github.com/Christ9038/Ydisks-Xianyu-Helper.git
cd Ydisks-Xianyu-Helper
cp .env.example .env

# 2. 修改 .env 填入自己的强密码与主密钥
# POSTGRES_PASSWORD=...
# XIANYU_DATA_KEY=...

# 3. 启动应用 (会自动拉取 GHCR 镜像并初始化 PostgreSQL 17)
docker compose up -d

# 4. 浏览器访问 http://localhost:8080，使用 admin 账号登录
Terminal / Bash (Build from Source) 
# 1. 构建 React 前端静态资源
npm --prefix frontend ci
npm --prefix frontend run build

# 2. 初始化管理员账号 (使用默认 SQLite)
mkdir -p data
go run ./cmd/server \
  -init-admin \
  -db data/xianyu_data.db \
  -admin-password '设置管理员密码'

# 3. 启动服务端 (默认监听 :8080)
go run ./cmd/server -db data/xianyu_data.db -addr :8080
FAQ

常见问题答疑

首次部署如何登录管理后台？
使用 Docker Compose 部署时，服务在启动时会自动读取 .env 文件中的 XIANYU_ADMIN_PASSWORD 创建管理员，默认用户名统一为 admin。使用源码构建时，可运行 go run ./cmd/server -init-admin -db ... -admin-password '你的密码' 初始化。
XIANYU_DATA_KEY 加密密钥的作用是什么？
XIANYU_DATA_KEY 用于对保存到数据库中的敏感 Cookie、闲鱼账号密码、设备 Token、AI API Key 及通知秘钥进行 AES-256-GCM 强加密。在生产环境部署前必须固定并妥善离线备份。密钥更换会导致原数据库中已加密的数据无法解密。
扫码登录后掉线或提示风控如何处理？
项目内置自动续期调度器。如果闲鱼平台触发安全校验或人脸识别，请在管理后台“账号管理”中查看提示，并使用手机闲鱼 App 扫描二维码或完成安全验证。同时请确保服务器时间与 NTP 保持同步。
无 Chromium 环境（如极轻量 VPS）能否运行？
可以使用 -no-browser 启动参数运行纯 Go 后端与管理后台。但在没有 Chromium 的情况下，遇风控滑块自动通过能力将不可用。推荐直接使用官方 Docker 镜像（已预置 Chromium 与完整运行环境）。
