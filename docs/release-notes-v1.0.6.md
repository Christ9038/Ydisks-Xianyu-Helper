# 发布说明：v1.0.6

发货模板

- 新增发货模板，可将多条发货消息组合成可复用的模板。
- 支持订单、买家、卡密和自定义变量，自动化规则可绑定对应卡密库存。
- 完善发货模板与自动化规则的配置和使用体验。

自动化发货与多规格订单

- 自动发货确认时携带发货凭证，提升失败恢复能力，减少重复发货和漏发。
- 优化多规格订单 SKU 的解析、匹配和自动发货，支持更复杂的规格组合。
- 改善订单同步和自动化任务状态处理，提升发货稳定性。

聊天与通知

- 新增浏览器新消息系统通知设置。
- 修复聊天联系人分页和历史会话加载问题。
- 优化聊天消息换行、未读状态和消息发送提示。

订单与兼容性

- 修复订单时间解析和创建时间显示偏差。
- 修复 PostgreSQL 订单批量写入问题，并完善多数据库兼容性。
